# IV Drip Simulator — 静的版（GitHub Pages検証用）

Gemini Canvasで作ったMVPを、リポジトリに置くだけでGitHub Pages公開できる単一ファイル（`index.html`、外部依存なし）に移植したもの。2026-11-10作成。

## 中身

- **シミュレーター**：滴下係数 10/15/20/60滴/mL × 輸液速度 10〜300 mL/h（プリセット 40〜200）。滴下筒のアニメーションが1滴の間隔に連動。読むのは「滴/分」「1滴の間隔」「15秒間の滴数」と計算式の展開。
- **2画面比較**：同じ速度で20滴/mLと60滴/mLを並べる。MVPにあった比較ポイント2の主語のねじれを修正済み（「60滴/mLでは1滴あたりの量が20滴/mLの1/3になるため、同じ量を送るには3倍の滴数が必要」）。
- **クイズ**：MVPの5問・1問ずつ進行から、**10問・一覧形式**に変更。各問タップで即フィードバック＋解説、スコア表示つき。
- 免責を明記（学習用。実際の投与は処方・指示と実測で確認）。
- 広告なし・解析なしの状態で置いてある（Pages検証フェーズの方針どおり）。

## 数値の検算（すべて確認済み）

式：滴/分 ＝ mL/h × 滴下係数 ÷ 60、1滴の間隔（秒）＝ 3600 ÷ (mL/h × 滴下係数)

| 条件 | 滴/分 | 間隔 |
|---|---|---|
| 60 mL/h・20滴/mL | 20 | 3.0秒 |
| 100 mL/h・20滴/mL | 33.3 | 1.8秒 |
| 100 mL/h・60滴/mL | 100 | 0.6秒 |
| 80 mL/h・15滴/mL | 20 | 3.0秒 |
| 120 mL/h・20滴/mL | 40 | 1.5秒 |
| 50 mL/h・60滴/mL | 50 | 1.2秒 |
| 30 mL/h・20滴/mL | 10 | 6.0秒 |
| 200 mL/h・15滴/mL | 50 | 1.2秒 |
| 2秒に1滴・20滴/mL | 30滴/分 → 90 mL/h | — |
| 120 mL/h・60滴/mL | 120 | 0.5秒 |

15秒カウント：100 mL/hで20滴/mLは約8滴、60滴/mLは25滴。

## GitHub Pagesでの公開手順（Stage 0）

1. GitHubで新規リポジトリを作成（例：`iv-drip-simulator`、Public）
2. この `index.html` をリポジトリ直下に置いて push
3. Settings → Pages → Build and deployment → Source を「Deploy from a branch」、ブランチ `main`・フォルダ `/ (root)` にする
4. 数分後に `https://<ユーザー名>.github.io/iv-drip-simulator/` で公開される

## 反応の測り方（公開前に仕込むもの）

- アクセス解析：Cloudflare Web Analytics（クッキー不要・無料）のスニペットを `</head>` の直前に追加するのが手軽。GA4でも可。
- 共有導線：X・note・周囲の医療者／看護学生への共有リンクを用意してから公開する。置いただけでは流入ゼロのため、「反応なし」がツールの問題か露出の問題か切り分けられない。
- 広告はこの段階では入れない（GitHub Pagesは商用ホスティング用途が規約上グレー、AdSenseは自前ドメイン前提）。手応えが出たら独自ドメインへ移行してから広告をつける。

## Stage 1（手応えが出た場合）

- 独自ドメイン取得 → Pagesにカスタムドメイン設定（旧URLからリダイレクト可）
- AdSense審査（ドメイン単位）＋広告コードはアプリページにだけ設置
- 「滴下計算 覚え方」などの解説記事をStudy PRIME側に置き、アプリへの導線を作る
